## Editar medios

1. Copia tus fotos WebP o AVIF y videos MP4 a assets/.
2. Para el hero y el portafolio, busca el bloque correspondiente en index.html por #hero o #project. En imágenes que tengan srcset, actualiza tanto src como srcset para servir los archivos correctos en cada pantalla.
3. Para la fotografía automotriz, reemplaza el bloque private-image-placeholder en private-clients/index.html por una etiqueta img con src="../assets/tu-foto.webp", alt descriptivo y dimensiones. La clase private-image-placeholder conserva el marco.
4. Para reemplazar el logo, actualiza assets/fomo-effect-logo.png.

Los enlaces de contacto usan el número de WhatsApp recuperado del sitio anterior. Los formularios locales requieren un receptor confirmado para activar el envío. El diagnóstico antiguo usaba una respuesta opaca que no permite verificar si se recibió.
